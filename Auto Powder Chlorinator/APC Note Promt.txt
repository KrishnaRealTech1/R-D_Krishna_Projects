Auto Powder Chlorinator:

We Use Calcium Hypochloride(Ca(CIo)2) Powder For Disinfecting the drinking water By adding.
For 1000Lit of water we use 4Grams of Calcium Hypochloride powder in 10lit of water for Chlorine Solution making.
For 10000Lit of Water we use 43Grams of Calcium Hypochloride powder in 12lit of water for Chlorine Solution making.

Rest it for 15Mins, After 15mins the Chlorine Solution which we make will be dissolve in the tank of 1000Lit or 10000lit.
mix it in that 1000Lit water for 30Mins.




Material Used:

 1). STM32F401CCU6           - For Control the Circuit.

 2). Vibrator          	     - For Vibrator the Calcium Hypochloride(Ca(CIo)2) Container.
 
 3). Screw Conveyor  		 - For Transfer the Calcium Hypochloride(Ca(CIo)2).
 
 4). Weight Scale    		 - For Measure Calcium Hypochloride(Ca(CIo)2).
 
 5). Rotate Motor   	     - For Transfer Calcium Hypochloride(Ca(CIo)2) For Solution Mixing.
 
 6). Mixer Motor    	     - For Mixing Chlorine Solution.
 
 7). Water-IN Solinoid       - For Water IN Control.
 
 8). Water-Out Solinoid      - For Water OUT Control.
 
 9). Drain-OUT Solinoid      - For Drain the deposites in Mixing tank.
 
10). Dosing Pump             - For Dosing the Chlorine solution to the Tank.

11). Float 1(Top)            - For Control the water filling.

12). Float 2(Bottom)         - For Control the water draining.

13). 16x2 I2C LCD Display    - For Display the Process and Monitoring.

14). RTC Module              - For Day Date & Time.

15). Bluetooth (HC-05)       - For Offline Control.

16). GSM Board               - For Transfer the Data to Server and for Controls.

17). Bubbler Motor			 - For Mixing the Chlorine Solution with Water.

Process:

Power ON (Manual)

 1). After 10secs of Power ON, Give 3.3V Trigger for 3secs to G-Key in GSM Board.

 2). After 3Secs Cut-OFF the 3.3V Trigger for G-Key in GSM Board.

 3). Dosing I/O will Always Low. When Dosing I/O is High, Start the Operation.

 4). Turn ON Mixer Motor & Water-IN Solinoid.

 5). Turn OFF Water-IN Solinoid & Mixer Motor, when Float 1(TOP) gets High.

 6). Turn ON Drain-OUT Solinoid for 5mins.

 7). Turn ON Vibrator & Mixer Motor & Water-IN Solinoid & Screw Conveyor & Weight Scale.

 8). Turn OFF Screw Conveyor, When Weight Scale Data reach set Valve (Example - 40Grams).

 9). Turn ON Rotate Motor for 2Secs. 

10). Turn OFF Weight Scale & Vibrator.

11). Turn OFF Water-IN Solinoid, When Float 1(Top) gets High.

12). After 3Mins, Turn OFF the Mixer Motor. 

13). Rest For 15Mins.

14). After 30Mins, Turn ON Water-Out Solinoid & Dosing Pump.

15). Turn OFF Dosing Pump and Water-Out Solinoid, When Float 2(Bottom) gets Low.

16). Turn ON Drain-OUT Solinoid for 5Mins.

17). Turn ON Water-IN Solinoid & Mixer Motor.

18). Turn OFF Water-IN Solinoid & Mixer Motor. After Float 1(Top) gets High.

19). Turn ON Bubbler Motor for 30Mins.

20). Turn ON Drain-OUT Solinoid for 5Mins.

21). System will goes for Rest or IDEL.

22). Again Start the Process, When Dosing I/O gets High.


Bluetooth Interface:

 1). "WS-40"                - Weight Scale Set for 40Grams (If "WS-20" it will set to 20Grams).
 
 2). "DOSEON"               - Start the Dosing Process.
 
 3). "DRAINOUT-5"           - Drain-Out Solinoid will ON for 5Mins(If "DRAINOUT-2" it will Turn ON For 2Mins).
 
 4). "SETTIME-HH/MM"        - If "SETTIME-9:30" set the time as 9:30.
 
 5). "SETDATE-DD/MM/YYYY"   - If "SETDATE-01/09/2025" set the Date to 01/09/2025.
 
 6). "SETDAY-1"             - Set Day as Sunday.
 
 7). "SETDAY-2"             - Set Day as Monday.
 
 8). "SETDAY-3"			    - Set Day as Tuesday.
 
 9). "SETDAY-4"			    - Set Day as Wednesday.
 
10). "SETDAY-5" 		    - Set Day as Thursday.

11). "SETDAY-6"             - Set Day as Friday.

12). "SETDAY-7"			    - Set Day as Saturday.



I2C LCD Interface:
 
 1). LCD Should Always Print "RealTech Systems" and Day Date And Time.
 
 2). When the Process is Start, the LCD Should Print "Process Starts".
 
 3). When the Dosing Pump is ON, the LCD Should Print "Dosing Start".
 
 4). When the all Process Stoped and Bubbler Motor is in OFF Condition after all process, The LCD Should Print "Process Completed".
 
 5). Then Again LCD Should Refresh and Shows "RealTech Systems", Day Date And Time.
 
 6). Day Format should be For Monday    - Mon
                          For TuesDay   - Tue
						  For Wednesday - Wed
						  For Thrusday  - Thu
						  For Friday    - Fri
						  For Saturday  - Sat
						  
 
 7). Date Format Should be DD-MM.
 
 8). Time Format Should be HH-MM.
