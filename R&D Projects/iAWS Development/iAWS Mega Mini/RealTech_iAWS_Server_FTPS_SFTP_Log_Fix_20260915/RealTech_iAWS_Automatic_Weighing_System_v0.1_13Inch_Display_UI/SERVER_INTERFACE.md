# RealTech iAWS v0.1 server transaction interface

The active server transaction payload is weight/camera/RFID based. It contains no payment processing requirement.

Core payload information includes:

- schemaVersion: `iAWS-v0.1`
- transactionId
- siteId / deviceId / laneId
- direction: IN or OUT
- RFID number
- vehicle metadata when available
- captured weight in kg
- configured target weight in kg
- targetReached flag
- four camera capture/upload records
- processed timestamp
- local/server synchronization state

See `Services/ServerSyncWorker.cs` for the exact JSON object generated by the current source.
