# RealTech iAWS v0.1 - UI Polish Fix

This update is intentionally UI-only. Existing weighing, RFID first-wins, camera, barrier, buzzer, signal, server sync, MQTT and storage logic is unchanged.

## Fixes
1. Configuration/Data/File sub-menu text is now dark on the white popup so menu options are always visible.
2. IN RFID and OUT RFID displays now use strong colored 2.5 px strokes, larger text and tinted backgrounds.
3. The lane hardware section now uses the available width instead of leaving a large empty area.
4. Signal/buzzer modules and barrier cards are larger and more balanced.
5. The right information column is fixed to a practical width so branding, date/time, COM status and live weight do not clip.
6. Camera cards, logs, lane cards, spacing, colors and borders were normalized into one consistent dashboard style.
7. No event handlers, bindings, commands or processing logic were removed.
