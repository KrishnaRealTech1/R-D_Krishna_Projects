Materials Used:
1). Nuvoton - N76E003AT20 = 1
2).5v Sugar Cube Relay = 1
3). 78L05 Regulator = 1
4). 1.1A Resettable Fuse = 1
5). 2-Pin RMC Male and Female = 2
6). LED 3mm RED/Green/Blue = 1
7). 10K CFR 1/4W Resistor = 3
8). 104 Capacitor = 2
9). EEPROM (24C04) = 1
10). 3 Pin DIP Switch = 2
11). BC847 Transistor


Material Purpose:
1). N76E003AT20 - For Control.
2). 5V Sugar Cube Relay - For ON/OFF Output.
3). 78L05 Regulator - For Give Power for Controller.
4). 1.1A Resettable Fuse - For Output Protection.
5). 2Pin RMC Male/Female (Connector) - For Input And Output.
6). RED LED - For OFF Time.
7). GREEN LED - For ON Time.
8). BLUE LED - For Power Indication.
9). 10K Resistor - For LEDs.
10). 104 Capacitor - For Input and Output of Regulator.
11). EEPROM - For Store ON/OFF Time.
12). 3Pin DIP Switch - For ON Time Control And OFF Time Control.
13). BC847 Transistor - For control the relay coil.

Operation:

Version 1.1 - 
1). Default Timer : 5Hours ON and 3Hours OFF.


Version 1.2 - 
1). DIP Switch Possibility For ON/OFF. For ON Time DIP Switch,
    000 - 1Sec Relay ON.
	001 - 2Sec Relay ON.
	010 - 3Sec Relay ON.
	011 - 4Sec Relay ON.
	100 - 5Sec Relay ON.
	101 - 6Sec Relay ON.
	110 - 7Sec Relay ON.
	111 - 8Sec Relay ON.
	
    For OFF Time DIP Switch,
    000 - 1Sec Relay OFF.
	001 - 2Sec Relay OFF.
	010 - 3Sec Relay OFF.
	011 - 4Sec Relay OFF.
	100 - 5Sec Relay OFF.
	101 - 6Sec Relay OFF.
	110 - 7Sec Relay OFF.
	111 - 8Sec Relay OFF.

2). Relay will ON/OFF The Output. When the Controller give 5V(HIGH) to the Relay Coil, It will Turn ON. When the Controller Gives (LOW) Relay will Turn OFF.
3). Relay's ON and OFF time will be Controlled by ON DIP Switch And OFF DIP Switch.
4). ON Time and OFF Time Will be Stored in EEPROM IC. During Powerloss it will stored ON/OFF Time and Resume it after Power ON.


PIN Mapping:
1).  P0.5 = OFFTime DIP SW1
2).  P2.0 = Reset
3).  P1.5 = SCL for 24c04 eeprom
4).  P1.4 = SDA for 24c04 eeprom
5).  P1.3 = Transistor Base
6).  P1.2 = Power Indication LED(Blue)
7).  P1.1 = Relay(Transistor) ON Indication LED (Green)
8).  P1.0 = Relay(Transistor) OFF Indication LED (Red)
9).  P0.0 = ONTime DIP SW3
10). P0.1 = ONTime DIP SW2
11). P0.2 = ONTime DIP SW1
12). P0.3 = OFFTime DIP SW3
13). P0.4 = OFFTime DIP SW2
