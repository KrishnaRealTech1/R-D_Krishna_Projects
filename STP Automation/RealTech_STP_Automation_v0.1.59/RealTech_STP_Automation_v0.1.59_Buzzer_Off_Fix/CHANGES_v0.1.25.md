# Changes in v0.1.25

- Automatic registered-vehicle RED commands now include the detected vehicle number:
  - `IN RED <vehicle number>`
  - `OUT RED <vehicle number>`
- Detailed RED commands continue to update the IN/OUT red signal indicators in the UI.
- Capture Storage is compact and bottom-aligned with the OUT Flow area.
- Status Log and Server Log now span the full application width below the lane flows.
