# Changes in v0.1.36

## Exceptional Approval mobile-number validation

- Mobile Number now requires exactly 10 digits before Exceptional Approval can continue.
- The field accepts ASCII digits `0` to `9` only.
- The field maximum length is limited to 10 digits.
- Pasting content that would make the field longer than 10 digits is rejected.
- The validation message now clearly requests a valid 10-digit mobile number.
- Approver Name alphabetic-only validation remains unchanged.

## Version

- Updated application version to `0.1.36`.
