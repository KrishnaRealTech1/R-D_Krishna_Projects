# Changes in v0.1.35

## Exceptional Approval input validation

- Approver Name now accepts alphabetic characters and spaces only.
- Numbers, punctuation, and symbols are blocked while typing in Approver Name.
- Invalid text pasted into Approver Name is rejected.
- Mobile Number now accepts ASCII digits `0` to `9` only.
- Invalid typed or pasted mobile-number characters are rejected.
- Mobile Number remains validated as 7 to 15 digits before approval can continue.
- Added clear field tooltips and inline validation messages.
- Reduced the Mobile Number field maximum length from 20 to 15 to match validation.

## Version

- Updated application version to `0.1.35`.
